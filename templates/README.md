# SAGE — Templates

Starting point files for each SAGE artifact. Use these as reference or copy them to your project.

| File | Use for |
|---|---|
| `spec.template.md` | Writing `spec.md` from scratch |
| `behavior.template.md` | Understanding `behavior.md` structure |
| `pr.template.md` | Understanding `pr.md` structure |
| `doc.template.md` | Understanding `doc.md` structure |
| `harness/android-compose.md` | Android + Jetpack Compose + MVI + Hilt harness |
| `harness/generic.md` | Blank harness template for any stack |

More harness templates welcome — see [Contributing](../README.md#contributing).
